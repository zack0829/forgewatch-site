# Forgewatch — B2B SaaS Marketing Site

A 6-page responsive marketing website for a fictional predictive-maintenance
platform, built as a sample to demonstrate a clean blueprint-to-production workflow.

**Live demo:** [https://forgewatch-site.vercel.app/]
**Stack:** HTML · CSS · JavaScript · bundled with Vite · deployed on Vercel

---

## Tech stack

- **Build tool:** Vite
- **Markup & styling:** HTML5 + CSS (`css/style.css`)
- **Scripting:** vanilla JavaScript (`js/app.js`)
- **Deployment:** Vercel (GitHub-based workflow)

A deliberately lightweight, portable static site — no CMS, no framework lock-in.

## Getting started

Requires Node.js 18+.

```bash
# install dependencies
npm install

# run the dev server
npm run dev
```

Vite will print a local URL (typically [http://localhost:5173](http://localhost:5173)).

```bash
# build for production (outputs to dist/)
npm run build

# preview the production build locally
npm run preview
```

## Deployment

The site deploys to Vercel directly from this GitHub repository:

1. Import the repo into Vercel.
2. Vercel detects Vite automatically. If you need to set it manually:
   - **Build command:** `npm run build`
   - **Output directory:** `dist`
3. Each push to the main branch triggers a new deployment.
4. A custom domain can be added under **Project Settings → Domains**.
